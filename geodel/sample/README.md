# Synthetic sample

`places.geojson` contains two invented points in EPSG:4326 (longitude, latitude).
Names and coordinates are illustrative; no customer or surveyed data is included.

Drag the file into QGIS, select its vector layer in GeoDel, and upload it to a
Workspace you control. Or use Browse to upload the GeoJSON unchanged.
Live upload requires an account, Personal API Key, internet and an active
trial/subscription. Delete the test upload in GeoDel when finished.
